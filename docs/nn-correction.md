# 「ん」の打ち忘れ補正

`ん` は 2打鍵（`nn`）を要する唯一のかなです。1回で済ませてしまうと別のかなになり、
気づかないまま変換されます。Karukan はこれを2段構えで扱います。

## 末尾の `n` は `ん` になる

語末の `n` は、それ以上ルールが伸びないので確定時に `ん` になります。

```
nihon   →  にほん
kan     →  かん
karukan →  かるかん
```

以前は literal な `n` のまま確定していました（`にほn`）。他の日本語IMEと同じ挙動に揃えています。

入力途中の `n` は待機したままなので、`na`・`nya` は従来どおりです。`ny` のまま確定した場合は
`んy`（`n` が確定し `y` はそのまま）になります。

## 途中の `n` は「もしかして」候補になる

語中の `ん` は確定のしようがありません。`かに` と `かんい` はどちらも正しい日本語だからです。
そこで Space で変換したとき、**`n` を1つ足した読み**でも変換し、`もしかして` 付きの候補として
並べます。

```
kani        →  かに      ← 打った通り（候補の先頭）
                かんい    もしかして

konnichiha  →  こんいちは  ← 打った通り
                こんにちは  もしかして

shinya      →  しにゃ    ← 打った通り
                しんや    もしかして
```

補正はかなのパターン表ではなく**打鍵そのもの**に対して行います。`n` を1つ挿入して変換し直すだけで、
母音の前（`kanni`）・な行の前（`konnni`）・や行の前（`shinnya`）のすべてを1つのルールで拾えます。

### 仕様

- **先頭には来ません。** 補正はあくまで推測なので、Space で最初に選ばれるのは常に打った通りの読みです。
- **1回の変換につき最大2つ**まで試します。`n` の数だけ推論が走るのを防ぐためです。
- **打った通りの読みと同じ結果になる補正は出ません。** 直すところがない語のコストはゼロです。
- **確定すると「打った通りの読み」で学習します。** `かに` → `かんい` が記録されるので、
  同じ打ち間違いを次にしたときは 📝学習 の候補として即座に出ます。打ち間違いを覚えさせて
  実用上の手数を減らすのが狙いです。不要なら変換中に Ctrl+Backspace で履歴から消せます。
- モデルが未ロード・応答なしのときは、直した**かな**そのものが候補になります。

## `n` を3回打つ場合

`こんにちは` は `konnnichiha`（`n` 3回）です。`ko` + `nn`(ん) + `ni`(に) と分解されるためで、
`nn` を常に `ん` とみなす仕様から来ています。この打ち方自体は変えていません。
打ち忘れたときは上の「もしかして」候補で拾ってください。
