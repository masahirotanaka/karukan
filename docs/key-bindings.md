# Key Bindings

Karukan のキーバインド一覧です。共通キーバインドは Linux (fcitx5) / macOS の両方で使えます。

## ひらがな入力モード

| キー | 動作 |
|------|------|
| 文字キー | ローマ字入力 → ひらがな変換 |
| Space / ↓ | かな漢字変換を開始 |
| Tab | かな漢字変換を開始（学習履歴を使わない） |
| Enter | ひらがなのまま確定 |
| Escape | 入力をキャンセル（ライブ変換中は1回目でライブ変換を解除してひらがなに戻り、2回目でキャンセル） |
| Backspace | 1文字削除 |
| Delete | カーソル位置の文字を削除 |
| ← → | カーソル移動 |
| Home / End | カーソルを先頭 / 末尾に移動 |
| Ctrl+B / Ctrl+F | カーソル移動（Emacs風 ← →） |
| Ctrl+A / Ctrl+E | カーソルを先頭 / 末尾に移動（Emacs風） |
| Ctrl+1〜9 | 表示中の候補を番号で選択・確定 |
| Ctrl+J | カーソル位置までの変換結果を固定する（続きを入力しても左側が変化しなくなる。[詳細](chunking.md)） |
| Ctrl+K | カタカナモードに切り替え |
| Ctrl+L | 打った通りの英数字に変換（`こんにちは` → `konnnichiha`）。変換後もひらがな入力が続く。続けて押すと大文字・全角へ（[詳細](#英数変換-ctrll)） |
| Ctrl+I | 変換を開始して🤖AI候補のビューを直接開く |
| Ctrl+T / Ctrl+R | 変換を開始してソース絞り込みビューへ（Ctrl+T は📝学習から、Ctrl+R は🔄記号変換から） |
| Shift+Space | 全角スペースを入力。入力中は設定した幅の空白を挟む（[詳細](symbols.md)） |

未入力の状態で `:` を打つと絵文字モードになり、`:smile` のようなクエリで絵文字を検索できます。Enterで先頭の絵文字候補を確定、Escapeで入力した文字列をそのまま確定します。

`Ctrl+1〜9`・`Ctrl+J`・`Ctrl+I`・`Ctrl+L`・`Ctrl+T` / `Ctrl+R` は変換モードでも使えます。どちらのモードでも「いま画面に出ているもの」に対して働きます。

## 変換モード

| キー | 動作 |
|------|------|
| Space / Tab / ↓ / Ctrl+N | 次の候補 |
| ↑ / Shift+Space / Shift+Tab / Ctrl+P | 前の候補 |
| PageDown / PageUp | 候補ページの移動 |
| Ctrl+1〜9 | 表示中の候補を番号で選択・確定 |
| Enter | 選択中の候補を確定 |
| Escape | 変換をキャンセル（ひらがなに戻る） |
| Ctrl+Backspace / Ctrl+Delete | 選択中の学習候補を履歴から削除 |
| Ctrl+J | カーソル位置で区切り、別候補が出る範囲を狭める（絞り込み中も表示は維持。[詳細](chunking.md)） |
| Ctrl+I | 🤖AI候補のビューを直接開く |
| Ctrl+L | 変換をやめて、打った通りの英数字にする（[詳細](#英数変換-ctrll)） |
| 「もしかして」付きの候補 | `ん` の `n` を1回打ち忘れた読みを直して変換した候補（[詳細](nn-correction.md)） |
| Ctrl+T / Ctrl+R （次 / 前） | 候補をソース別に絞り込み（📝学習→📚辞書→🤖AI→🔄記号変換をローテーション。📚はユーザー辞書とシステム辞書の両方で、ユーザー辞書が先。🔄は先頭に📅日付・時刻（きょう等の登録フレーズのみ、[詳細](date.md)）、末尾に素のひらがな/カタカナも並ぶ。全体に戻るには Esc→Space） |
| 文字キー・数字 | 確定せず読みを伸ばして変換をやり直す（インクリメンタルに候補が更新される。ソース絞り込み中はフィルタを維持したままビュー内で候補が絞られ、補助テキストに入力中の読みが表示される） |
| Backspace | 変換をキャンセルして入力編集に戻る（Escapeと同様）。ソース絞り込み中は読みを1文字縮めてビューに留まり、候補が広がる |
| ← → / Home / End / Ctrl+A・B・E・F | 変換を解いて入力編集に戻り、カーソル移動（ライブ変換中のカーソル移動と同じ挙動。ソース絞り込みも解除される） |

## モード切り替え

| キー | 動作 |
|------|------|
| Shift+英字 | 英数字モードに切り替え + 大文字入力 |
| Ctrl 単独タップ | 英数字/カタカナ → ひらがなモードに復帰（確定を待たずに戻せる） |
| Ctrl+K | カタカナモードに切り替え |
| Ctrl+L | 打った文字を英数字に変換し、ひらがな入力に戻る（[詳細](#英数変換-ctrll)） |
| Ctrl+I | 変換を開始して🤖AI候補のビューを直接開く |
| Ctrl+T / Ctrl+R | 変換を開始してソース絞り込みビューへ（Ctrl+T は📝学習から、Ctrl+R は🔄記号変換から） |
| Ctrl+Shift+V | 補助テキストの詳細表示を切り替える（推論時間・モデル名など） |
| Ctrl+Shift+L | ライブ変換のON/OFF |

### 英数字モード

英数字モードでは文字がローマ字変換されず、そのまま入力されます。日本語と英語を混ぜて入力し、Spaceで変換するとひらがな部分のみ変換されます。

例: `わたしはLinuxが` → 変換 → `私はLinuxが`

### 英数変換 (Ctrl+L)

`Shift+英字` が「これから英字を打つ」ためのキーなのに対し、`Ctrl+L` は**すでに打ってしまった文字**を英数字に直します。ローマ字入力の打鍵そのものが記録されているので、かなから逆算するのではなく打った通りの綴りが戻ります。

```
konnnichiha  →  こんにちは  →  Ctrl+L  →  konnnichiha
hello        →  へっぉ      →  Ctrl+L  →  hello
```

押すたびに大文字・全角へ巡回します（他のIMEのF10 / F9に相当）。同じ形になるものは飛ばされるので、数字だけの入力は半角↔全角の2つだけを回ります。

| 回数 | 表示 | 補助テキスト |
|------|------|--------------|
| 1回目 | `hello` | `[半]英字` |
| 2回目 | `HELLO` | `[半]英大文字` |
| 3回目 | `Hello` | `[半]先頭大文字` |
| 4回目 | `ｈｅｌｌｏ` | `[全]英字` |
| 5回目 | `ＨＥＬＬＯ` | `[全]英大文字` |
| 6回目 | `hello` | （1回目に戻る） |

**変換後はそのままひらがな入力が続きます。** モードを戻すキーは要りません。

```
hello  →  Ctrl+L  →  hello  →  ka  →  helloか
```

`Shift+英字` で入った英数字モードは、この変換で終わります。`Ctrl+K` で自分から選んだカタカナモードはそのまま残ります。変換のあとも**英字を打ち続けたい**ときは `Shift+英字` で直接入力に入ってください。

変換中（候補ウィンドウが出ている状態）でも押せます。巡回の途中で文字を打ち足すと巡回は終わり、次の `Ctrl+L` は打ち足したあとの内容から数え直します（`hello` → `Ctrl+L` → `ka` → `Ctrl+L` で `helloka`）。すでに英数字になっている文字に押した場合は、見た目が変わらない形を飛ばして次の形（大文字）になります。

`Ctrl+Shift+L` はライブ変換のON/OFFで、別のキーです。

## Linux (fcitx5) 固有

| キー | 動作 |
|------|------|
| 右Super・右Altなど右側の修飾キー / 変換 (JIS) | 英数字/カタカナ → ひらがなモードに復帰 |
| Ctrl 単独タップ | 同上。押して何も押さずに離したときだけ発動するので、Ctrl+L などの組み合わせは影響を受けません |

## macOS 固有

| キー | 動作 |
|------|------|
| かな (JIS) | ひらがな入力モードへ戻る。Ctrl+K のカタカナモード、Shift+英字で入った英数字モードのどちらからでも有効（Linux版の右Super/変換キーに相当） |
| 英数 (JIS) | 変換中テキストを確定して直接入力モードへ切替 |
| 右⌘ 単独タップ | かなキーと同じ（ひらがな入力モードへ戻る）。JISかなキーが無いUS配列向けの代替で、Karabinerなどの設定は不要。⌘C など他のキーと組み合わせた場合や、他の修飾キーと同時押しした場合は発動しない |
