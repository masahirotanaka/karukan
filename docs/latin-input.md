# 英字混じり入力

ローマ字入力には「ここからここまでは英単語」と伝える手段がありません。`closesite` と
打てば `c` はどのルールにも届かず素通しになり、`lo` は小書きの逃げ道を撃って
「cぉせして」になります。これは何の読みでもありませんが、打鍵のほうはまだ意味を
持っています — `close` は辞書が「くろーず」の表記として知っている語で、`site` は
「して」です。

karukan はその読み直しを自動でやります。

| 打鍵 | 素のローマ字変換 | 読み直した結果 |
|---|---|---|
| `closesite` | cぉせして | closeして |
| `rustde` | るstで | rustで |
| `githubwo` | ぎてゅbを | githubを |
| `EPICha` | EPICha | EPICは |

`[conversion] latin_input = false` で止められます。

## 単語の切れ目をどう決めるか

単語リストはシステム辞書の英字表記そのものです（同梱の辞書で約6万語）。katakana の
読みに既に答えている語がそのまま載っているので、`close` `rust` `github` は入って
いて、新しいデータファイルは1つも増えません。辞書が無いときはこの機能は何もしません。

走査は**長いものから**です。`cl` も `clos` も実在する辞書表記で、どちらも後ろが
かなに変換できてしまうので、長いものから取らないと `closesite` が `cl` + 「おせして」
になります。同じ理由で `githubwo` は `git` ではなく `github` で切れます。

語の**前後がきれいなかなになること**が条件です。素通しの英字が残る切り方は切り方と
見なしません。だから `sushi` は「すし」のままで、`sushi` という辞書表記があっても
英単語とは読まれません — ローマ字としてきれいに読めている入力には、そもそも説明の
必要がないからです。

大文字は打ったとおりに残ります（`GitHubwo` → `GitHubを`）。

## 英字モードでの切れ目

英字モード（Shift+英字）は打鍵をそのまま確定するので、切れ目を教えてくれる素通しの
ゴミがありません。代わりに**大文字から小文字への変わり目**が境界になります。

- 2文字以上の大文字の並びで、それが単語リストにあること
- 続きは小文字だけで、きれいなかなになること
- その小文字に `l` と `x` を含まないこと

`l` `x` は小書きかなの逃げ道で、英単語はそこに寄りかかります（`Hello` → `H` +
「えっぉ」）。除外しておくと、ふつうの英単語は英単語のまま残ります。`MacBook` は
小文字の続きに大文字が混ざるので対象外、`QQQha` は辞書が知らない頭なので対象外です。

## 読み直しは「導出」であって書き換えではない

結果は打鍵から毎回計算し直すだけで、編集中のバッファには触りません。だから
Backspace は `close` の `e` を消し（それが作った「て」ではなく）、Ctrl+L には
元の打鍵がそのまま残っています。

読み直した結果はそのまま Chunk 分割に渡ります。英字は日本語ではないので
`group_chunks` が壁として扱い、モデルに届くのは周りのかなだけです
（[Chunk](chunking.md) 参照）。`rustdekaihatu` が「rustで開発」になるのはこのためです。

## かな読みに英字表記を出さない

裏返しの決まりとして、**読みが全部かなのときは英字表記の候補を出しません**。

- システム辞書の「くろーず → close」
- モデルの「クローズシテ → closeして」（モデル自身のビームで2位に居ます）
- 学習済みの「えぴっく → EPIC」

英字は英字で打つ（`latin_input`）という住み分けです。`[conversion]
alphabet_from_kana = true` で全部戻ります。

落とすのは**読みが持っていなかった英字**だけです。読みと表記を英字の連なりごとに
突き合わせるので、

- 「Firebaseぷろじぇくと」→「Firebaseプロジェクト」は残ります（`Firebase` は読みに
  ある＝自分で打った）
- 「えぴっくyは」→「EPICyは」は落ちます（読みにあるのは打ち間違いの `y` だけで、
  `EPIC` ではない）
- 読みにかなが1文字も無いときは英字入力そのものなので対象外です。ユーザー辞書の
  生打鍵ショートカット（読み `m` → メールアドレス）はこれで生き残ります

ユーザー辞書は参照されるどこでも対象外です。自分で登録するというのは、その読みに
その表記があると宣言することだからです。

ライブ変換でモデルが英字を返したチャンクは、その場で一度だけビームを引き直して
日本語のまま残った候補に差し替えます。汚染されたチャンクだけが2回目の推論を払い、
きれいな代案が無ければ元の答えを使います。
